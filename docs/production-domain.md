# Продакшен-установка с доменом: CRM и сайт сервиса

Цель: владелец автосервиса указывает свой домен при установке и получает два адреса.

- `crm.domain.com` — WrenchCRM для сотрудников.
- `domain.com` (и `www.domain.com`) — простой сайт автосервиса с собственной админкой.

Сайт и CRM — одна установка: общая база, общие пользователи и права, единые реквизиты. Сайт показывает только публичные данные и принимает заявки, которые сразу попадают в воронку CRM.

## Установка

- `install.sh` и `install.ps1` спрашивают домен (необязательно). Без домена всё работает как сейчас, по адресу `http://localhost:3000`.
- С доменом в комплект добавляется обратный прокси с автоматическими сертификатами Let's Encrypt (Caddy): `crm.domain.com` ведёт в CRM, `domain.com` и `www.domain.com` — на сайт. Порты 80 и 443, HTTPS принудительный, `RAILS_ASSUME_SSL` и `RAILS_FORCE_SSL` включаются сами.
- Режим «за существующим прокси» (Nginx Proxy Manager, Traefik, nginx): без своего Caddy, контейнер подключается к сети прокси, установщик выводит, какие два хоста там создать.
- Проверка перед выпуском сертификатов: оба имени резолвятся на этот сервер; если нет — понятная подсказка, какие A-записи добавить у регистратора.
- Приложение отличает CRM и сайт по имени хоста; домены задаются в `.env` (`CRM_HOST`, `SITE_HOST`), с проверкой `config.hosts`.

## Сайт сервиса

Публичная часть, без входа:

- Главная: название и логотип, слоган, баннеры-слайдер (картинка, заголовок, текст, кнопка), блок «Почему мы», акции.
- Услуги и цены: из справочника работ CRM — только отмеченные «показывать на сайте», по категориям, с ценой «от».
- Онлайн-запись: форма (имя, телефон, автомобиль, что нужно, удобные дата и время) с обязательной отметкой согласия на обработку ПДн и ссылкой на политику. Заявка создаётся в CRM с каналом «Сайт», появляется на доске заявок и в счётчике в меню. Защита от спама: honeypot-поле и ограничение частоты.
- Свободные окна: по желанию показывать ближайшие свободные слоты из календаря записи (без имён и машин).
- Контакты: адрес, телефон, мессенджеры, график работы, карта (Яндекс Карты по адресу), реквизиты из настроек.
- Отзывы: публикуемые вручную.
- Страницы: «О нас», гарантии, политика обработки ПДн (уже есть), произвольные страницы.
- SEO и соцсети: заголовок и описание каждой страницы, Open Graph, `sitemap.xml`, `robots.txt`, разметка LocalBusiness / AutoRepair (schema.org), подключение Яндекс Метрики по номеру счётчика (с уведомлением о cookie).
- Адаптивная вёрстка и быстрая загрузка: страницы без лишнего JavaScript, кэширование.

Админка сайта — раздел в CRM «Сайт» (право «Управление сайтом»):

- Основное: название, логотип, фавикон, слоган, цветовая схема из нескольких готовых, телефон и мессенджеры, график работы.
- Баннеры: загрузка изображений, порядок, период показа, включение и выключение.
- Акции и новости: заголовок, текст, картинка, срок действия.
- Страницы: редактор с простым форматированием, порядок в меню.
- Услуги: какие показывать, описание для сайта, цена «от».
- Отзывы: добавление, публикация, порядок.
- Онлайн-запись: включить или выключить, какие поля обязательны, текст после отправки, кого уведомлять о новой заявке.
- Предпросмотр изменений перед публикацией.

## Что понадобится в коде

- Хранение файлов (логотип, баннеры, картинки): Active Storage на диск в томе Docker, превью изображений, ограничение размера и типов.
- Маршрутизация по хосту: публичные контроллеры сайта на `SITE_HOST`, CRM на `CRM_HOST`; без доменов сайт доступен по пути `/site` для проверки.
- Модели сайта: настройки сайта, баннеры, страницы, акции, отзывы, флаг «на сайте» у работ.
- Связь с CRM: заявка с сайта создаёт `Lead` (канал «Сайт», согласие на ПДн фиксируется в заявке и переносится в карточку клиента при его создании).
- Бэкапы: в зашифрованную копию добавляются загруженные файлы.
- Тесты: маршрутизация по хостам, форма записи (согласие обязательно, спам отсекается), админка, установка с доменом и без.

## Порядок работы

1. Маршрутизация по хосту, `CRM_HOST` / `SITE_HOST`, хранение файлов.
2. Публичный сайт из данных CRM: главная, услуги, контакты, политика, онлайн-запись в воронку.
3. Админка сайта: основное, баннеры, страницы, акции, отзывы.
4. Установщик с доменом: Caddy и автоматический HTTPS, режим за существующим прокси, проверка DNS.
5. SEO, Метрика, свободные окна записи.
